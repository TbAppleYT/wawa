HOSTING / OPERATION

Upload station.html and simple-control-panel.html to a static website host. Your host will assign the real HTTPS website address. This listener connects directly to your remote audio server mount; no local web server is required.

The eas-webdec-test server generates forecasts, inserts announcements, loops your uploaded audio, and serves the MP3 stream directly. HTML hosting does not run that source. A secure public HTTPS mount is required for a secure website.

Browsers require you to press Connect before audio starts. A lost connection is retried while this receiver is enabled. Audio playback may stop when your device sleeps.
